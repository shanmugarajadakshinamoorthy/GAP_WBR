Gap Weekly Business Review

version_3 has the latest code

# Steps to set it up
 - clone the repository
 - make sure the raw data file is present. The file name is 'Brand_data_mock.csv'
 - Open new terminal and switch to command prompt window
 - create virtual environment, activate and install requirements
     -- python -m venv .venv
     -- .venv\Scripts\activate
     -- pip install -r requirements.txt
 - Make sure you add the **.env** file
 - **step1_create_db.py** : run the Python files to create an initial set of prerequisite
 - streamlit run ui/app.py

If some packages are not available, please install them using "pip install package_name"
